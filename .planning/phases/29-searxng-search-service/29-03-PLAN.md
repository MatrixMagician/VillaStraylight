<objective>
Prove the SearXNG service actually works by issuing a REAL `format=json` search query and parsing `results[]` — never a health-200 (the project's "offload-asserting, never liveness" principle; mirrors `memoryProof`'s real `/v1/embeddings` round-trip). Wire it into the install flow gated on the persisted `WebSearchEnabled`, gating the service start on the rendered unit being present, and refusing-with-remediation on a FAIL.

This is a near-verbatim clone of the shipped `install_memory.go` readiness-by-real-query seam: a pure `eval*Proof` verdict core (unit-testable off-hardware via an injected probe), a `live*Proof` production seam reusing the `runProbeCurl` podman-over-villa.network helper, and the install.go gating block.

Purpose: SC#2 demands readiness be the actual query returning parseable JSON results — this plan is that proof.
Output: a real-query readiness proof + install wiring; the searxng install path fails closed (never false-green) when the service can't answer.
</objective>
