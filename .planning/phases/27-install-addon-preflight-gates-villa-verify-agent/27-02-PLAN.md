<objective>
Gate the coding-agent addon honestly at preflight and cover it at uninstall (INSTALL-04). New `preflight_agent.go` appends agent checks to the existing install gate (disk BLOCK, post-coder envelope BLOCK driven by `rec.Coder`, cloud-credential WARN, typed-Unknown → WARN) only when the addon is enabled — the honest-gating decision D-09. `uninstall.go` gains two always-removed ordered seams (the villa-owned crush binary + rendered `crush.json`); the staged coder GGUF follows the existing keep/remove-models flag and `config.toml` is left in place — the uninstall-scope decision D-10.

Purpose: Refuse-with-remediation on confident known-bad (no disk, no fit), surface the cloud-credential risk without blocking (the rendered config + env lockdown already neutralize it), and never false-BLOCK on an unprobeable signal (D-09). Uninstall reverses the addon's on-disk footprint deterministically — ordering is the contract (D-10).
Output: `cmd/villa/preflight_agent.go` + test; `runAgentChecks` fold in `install.go`; `removeAgentBinary`/`removeCrushConfig` seams + ordered teardown in `uninstall.go`; extended `uninstall_test.go`.
</objective>
