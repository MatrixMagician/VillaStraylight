## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub release CDN → host filesystem | Install seam streams + extracts the third-party tarball to $XDG_DATA_HOME/villa/bin. |
| villa process → crush process | `villa code` execs the binary, handing it the lockdown env. |
| user PATH → launcher | A user-installed `crush` on PATH must NOT be exec'd (D-05). |
| rendered crush.json → first-run write | The first-run absent path writes villa-rendered bytes (metachar-free, Plan 01) to ~/.config/crush; present-but-differs is never overwritten. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-07 | Tampering | install seam — unverified tarball reaching extraction | mitigate | Install verifies SHA-256 (via Plan-01 VerifyTarball) BEFORE any extraction; refuse-with-remediation on mismatch (Task 1, D-03). |
| T-26-08 | Tampering | tar extraction path traversal | mitigate | Extraction confined to $XDG_DATA_HOME/villa/bin via an assertInsideDir guard; `..`/absolute tar entries rejected; stdlib archive/tar, never shell `tar` (Task 1, V12). |
| T-26-09 | Elevation of Privilege | launching the wrong `crush` (PATH hijack) | mitigate | Deps.Launch execs the EXPLICIT villa-owned path agentBinPath(); never exec.LookPath / PATH resolution for the binary (Task 2, D-05). |
| T-26-10 | Information Disclosure | telemetry / autoupdate phone-home at launch | mitigate | Launch env sets CRUSH_DISABLE_METRICS=1, DO_NOT_TRACK=1, CRUSH_DISABLE_PROVIDER_AUTO_UPDATE=1 (Task 1/2, D-11) — belt-and-braces with the config kill switches (Plan 01); runtime egress proof is Phase 27. |
| T-26-11 | Tampering | silent drift auto-correction at launch | mitigate | runCode surfaces present-but-differs drift + remediation and EXITs; the only write path is the config-ABSENT first-run render (never overwrites an existing config) (Task 1/2, D-14). |

| T-26-13 | Elevation of Privilege | `villa code` auto-flipping coding mode | mitigate | code.go contains no `CodingMode = true\|false` literal; TestNoAutoFlipStructuralGuard stays green; coding-mode-OFF is a WARN, never a mutation (Task 2, D-12). |
