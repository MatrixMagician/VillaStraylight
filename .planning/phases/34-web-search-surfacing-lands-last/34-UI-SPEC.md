# Phase 34 — UI Design Contract

> Visual and interaction contract for the dashboard **Web Search panel** (SURF-05). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope:** ONLY the new hidden-until-data Web Search panel in the embedded control dashboard (`internal/dashboard/assets/`). The status `web_search` block (SURF-04), `villa doctor` checks (SURF-06), and backup/restore (SURF-07) are CLI/JSON contracts with no visual surface and are out of scope for this UI-SPEC.
>
> **Binding precedent:** This panel MUST mirror the existing `#memory-panel` (CTRL-02) and `#agent-panel` (SURF-01/D-05) verbatim. It introduces **zero new design tokens, zero new CSS classes is the goal** (add new classes ONLY if an existing one cannot be reused, and even then within the existing token vocabulary), **no new fetch, no new endpoint, no new probe** — it reads `report.web_search` off the SAME `/api/status` poll (`poll()` in `dashboard.js:820`).

## Color

Reuse the existing 60/30/10 split + semantic status palette from `dashboard.css` `:root` verbatim. **No new color values.**

| Role | CSS var | Value | Usage in this panel |
|------|---------|-------|---------------------|
| Dominant (60%) | `--bg-dominant` | `#0F1115` | Page background (behind the panel) |
| Secondary (30%) | `--bg-secondary` | `#1A1D24` | The panel surface itself (`.panel`) |
| Accent (10%) | `--accent` | `#3B82F6` | **Reserved — NOT used by this panel** |
| Destructive | `--destructive` | `#EF4444` | **NOT used by this panel** (no destructive action; quarantine is a count, not an error) |
| text-primary | `--text-primary` | `#E6E8EC` | Row labels, headings |
| text-muted | `--text-muted` | `#9AA0AA` | `.muted` captions, secondary detail |
| status-ready | `--status-ready` | `#22C55E` | `.status-dot.ready` / `.badge-ready` — service ready, outbound **bounded** (real recent verify PASS) |
| status-warn | `--status-warn` | `#F59E0B` | `.status-dot.warn` / `.badge-warn` — service loading/degraded, guard flagged/quarantined activity, **NOT-bounded** verdict |
| status-down | `--status-down` | `#EF4444` | `.status-dot.down` / `.badge-down` — service down |
| status-unknown | `--status-unknown` | `#6B7280` | `.status-dot.unknown` / `.badge-unknown` — typed-Unknown / stale-or-absent verify result |

**Accent reserved for (project-wide, do NOT extend here):** chat link, the model Switch primary button, focus rings, and the loaded-model left-border. The Web Search panel is read-only and MUST NOT consume accent.

**Honesty color rules (binding — mirror `renderMemory`/`renderAgent`):**
- A confident-good state → **green** (`badge-ready`). Reserved for: a real, recent `villa verify search` **PASS** ("outbound bounded"); a service `ready`.
- A confident-degraded-but-not-failure state → **amber** (`badge-warn`), **NEVER red**. Reserved for: service `loading`/degraded, a **not-bounded** verify verdict, guard activity (flag/quarantine counts present). Red (`status-down`) is reserved for a genuine service-`down` health row only.
- A stale, absent, or unevaluable signal → **gray** (`badge-unknown`) typed-Unknown, **never** green and **never** red. Reserved for: the outbound-bounded indicator when the cached `villa verify search` result is stale/absent; any field the report omits.

## Static Shell (HTML contract)

Add ONE `<section>` to `internal/dashboard/assets/dashboard.html`, **after `#agent-panel`** (the last panel today, line ~74–77), mirroring the agent-panel chrome verbatim. It ships with the `hidden` attribute.

```html
<!-- Web Search (SURF-05) — ships hidden (the memory-panel / agent-panel precedent);
     the poll loop unhides it ONLY when report.web_search is present
     (web_search_enabled=true). Web-search-off dashboards render pixel-identical
     to v1.4 (CTRL-02/D-03: no new fetch or endpoint — the panel reads
     report.web_search from the existing /api/status poll). XSS-safe: all
     server/web-derived values via textContent, never innerHTML. -->
<section class="panel" id="web-search-panel" aria-labelledby="web-search-heading" hidden>
  <h2 class="panel-heading" id="web-search-heading">Web Search</h2>
  <div id="web-search-body"></div>
</section>
```

**Contract invariants:**
- Panel ships with `hidden`; revealed only when `report.web_search` is truthy; **re-hidden** if the field disappears (so a web-search-off install renders pixel-identical to the prior version — the byte-identical-when-off property mirrored from memory/agent).
- New JS handles: `var webSearchPanel = document.getElementById("web-search-panel");` and `var webSearchBody = document.getElementById("web-search-body");` declared beside the existing `memoryPanel`/`agentPanel` vars (`dashboard.js:21–24`).
- A new `renderWebSearch(report)` function mirrors `renderAgent` exactly (same hidden/unhidden/`textContent=""` reset shape), called from the `/api/status` `.then` branch in `poll()` **after `renderAgent(report)`** (`dashboard.js:848`) and **NOT** from the `.catch` path (last-good stays under the existing stale-dimming).
- Reuse existing helpers only: `mutedP()`, `metricRow()`, `memoryBadgeRow()`, `groupThousands()`. Do not invent new row builders unless a sub-element genuinely cannot be expressed by these (and then keep it in the same class vocabulary).

## Panel Content (row-by-row contract)

Render rows in this order. Every server/web-derived value via `textContent`. Omit a row entirely when its field is absent (the honest empty state is **no row**, never a zero-filled or fabricated value — mirror `renderAgent`).

| # | Row | Source field (Claude's discretion on exact key) | Renderer | State mapping |
|---|-----|--------------------------------------------------|----------|---------------|
| 1 | Service health: `villa-searxng` | `web_search.services[]` health (`ready`/`loading`/`down`/`unknown`) | `.health-row` shape (dot + name + badge) reusing `healthClass`/`healthLabel`, **or** `memoryBadgeRow("villa-searxng", …)` | ready→green, loading→amber, down→red, unknown/absent→gray "unavailable" |
| 2 | Service health: `villa-websafe` | same | same | same as row 1 |
| 3 | Outbound bounded | `web_search.outbound_bounded` tri-state derived from cached `villa verify search` (`bounded`/`not-bounded`/`unknown`) + freshness stamp | `memoryBadgeRow("outbound", <label>, <cls>)` | **bounded** (real recent verify PASS)→green "bounded"; **not-bounded**→amber "not bounded"; **stale/absent**→gray "unavailable" + a `mutedP` caption (see Copywriting) |
| 4 | Verify freshness | `web_search.verify_checked_at` (RFC3339, verbatim) | `metricRow("egress checked", <timestamp>)` | OMITTED entirely when absent (no fabricated relative time — verbatim RFC3339, mirroring `last indexed`) |
| 5 | Guard verdicts | `web_search.guard.{strip,flag,quarantine}` counters (Phase 32) | one `metricRow` per non-omitted counter, `groupThousands()` formatted | Counts only. Present counts render as grouped integers. When the whole guard block is absent → OMIT all three rows (never fabricate 0). Amber badge ONLY if you choose to surface a single roll-up "guard activity" state; per the precedent, prefer plain count rows + a `badge-warn` only on a confident "active guard" roll-up |
| 6 | Last query freshness | `web_search.last_query_at` (RFC3339, verbatim) | `metricRow("last query", <timestamp>)` | OMITTED when absent (honest empty — never "never"/fabricated) |
| 7 | Outbound visibility | `web_search.last_query` and/or `web_search.last_fetched[]` (the searched terms / fetched URLs — **UNTRUSTED, web-derived provenance**) | `metricRow("searched", <text>)` / per-URL `metricRow` — **MANDATORY `textContent`, NEVER `innerHTML`** | OMITTED when absent. This is the most sensitive XSS surface in the panel: it surfaces attacker-influenceable strings (search queries, fetched URLs). It MUST go through `textContent` only |

**Hard rendering rules (binding):**
1. **XSS-safe always.** Every value in rows 1–7 — especially the row-7 query/URL provenance — is rendered via `createElement` + `textContent`. `innerHTML` is forbidden for any server/web-derived data. (`renderHealth` line 153 idiom; the panel surfaces *more* untrusted data than any existing panel, so this is non-negotiable.)
2. **Typed-Unknown, never false-green.** The outbound-bounded indicator (row 3) shows green ONLY for a real, recent verify PASS. Stale or absent → gray "unavailable", never green, never red. (Mirrors `readinessClass`/`renderAgent` pin convention.)
3. **No fabricated zeros.** Absent counters/timestamps → omit the row. (Mirrors `renderAgent` / `renderCumulativeUsage`.)
4. **No animation / no spinner.** Reduced-motion is already enforced globally; do not add one.
5. **Last-good under stale-dim.** `renderWebSearch` is not called on a failed poll; the global `setConnected(false)` stale-dim keeps last-good content (`dashboard.js:795`).

## Copywriting Contract

All copy is plain, lowercase row labels matching the existing panels (`embedding model`, `policy pin`, `recall index`). Remediation captions point at a real `villa` command.

| Element | Copy |
|---------|------|
| Panel title | `Web Search` |
| Primary CTA | **none** — this panel is read-only (no button, no write). Do not add a CTA. |
| Service row labels | `villa-searxng`, `villa-websafe` |
| Outbound row label | `outbound` |
| Outbound — bounded badge | `bounded` (green) |
| Outbound — not-bounded badge | `not bounded` (amber) |
| Outbound — unknown badge | `unavailable` (gray) |
| Outbound — unknown caption | `Outbound bound not verified — run villa verify search to confirm egress is bounded.` |
| Outbound — stale caption (verify result older than freshness window) | `Egress check is stale — re-run villa verify search.` |
| Egress checked row | `egress checked` → verbatim RFC3339 timestamp |
| Guard counter rows | `stripped`, `flagged`, `quarantined` → grouped integer counts |
| Last query row | `last query` → verbatim RFC3339 timestamp |
| Outbound visibility rows | `searched` → query text (verbatim, `textContent`); `fetched` → URL (verbatim, `textContent`) |
| Empty state (panel revealed, web_search present but no activity yet) | heading `No searches yet` + body `Web searches and their guard verdicts appear here once the assistant runs a search.` (mirror the `renderMemory` empty-state shape: `.model-empty-heading` + `mutedP`) |
| Error / degraded service caption (a service `down`) | rendered by the reused `healthLabel`/badge — `down` badge; no extra caption needed (consistent with the Health panel) |
| Destructive confirmation | **none** — no destructive action in this panel |

**Copy honesty rules:** never state "bounded"/"secure"/"safe" unless the cached verify result is a real recent PASS. Never imply a count is zero when it is merely unobserved (omit the row instead). Never render a relative time ("2 minutes ago") — verbatim RFC3339 only, matching `last indexed`.
