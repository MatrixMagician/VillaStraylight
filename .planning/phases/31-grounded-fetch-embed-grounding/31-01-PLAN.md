<objective>
Build `internal/websafe` — the pure, off-hardware-unit-testable fetch core that is the
sole producer of `page_content` (GUARD-01) with a comprehensive SSRF guard (GUARD-05)
and the verified OWUI external-loader HTTP contract glue (GROUND-01 page-production path).

This plan delivers ONLY the pure core + contract glue + tests. It touches no orchestrate
render, no config, no cmd wiring — those land in Plan 03 (which imports this core). The
core takes its network fetch via an injected `Deps` func-field seam so it is fully
unit-testable without a live network, keeping "orchestrate is the only intentionally-impure
module" intact (the live `*http.Client` is wired in `cmd/villa/websafe.go` in Plan 03).

Purpose: every byte OWUI embeds or shows the model must pass through villa code, and that
code must refuse to fetch internal/metadata endpoints even under DNS-rebinding and redirect
attacks. This is the load-bearing security surface of Phase 31.
Output: the `internal/websafe` package (4 source files) + 2 table-driven test files.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OWUI (villa.network) → villa-websafe handler | OWUI POSTs result URLs; the body is untrusted input crossing into villa |
| villa-websafe → upstream result sites (outbound) | every fetched URL is fully untrusted; the response body is attacker-controlled |
| upstream redirect → villa-websafe dialer | a 2xx→302 chain can pivot a public host toward an internal IP |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-01 | Information Disclosure | `fetchOne` / `control` (outbound) | mitigate | `net.Dialer.Control` validates the CONNECTED IP against `rejectPrefixes` (loopback/RFC1918/link-local/CGNAT/ULA/metadata) — rejects SSRF to 169.254.169.254 and internal services (GUARD-05) |
| T-31-02 | Spoofing | DNS resolution for a fetched host | mitigate | validation runs in `control` AFTER DNS, on the actual socket IP (not the hostname) — defeats DNS-rebinding TOCTOU (Pitfall 4) |
| T-31-03 | Information Disclosure | redirect handling | mitigate | `CheckRedirect` re-runs scheme + hostname reject every hop and caps at MaxRedirects (5); the Control hook re-validates the resolved IP on each new dial |
| T-31-04 | Denial of Service | `fetchOne` body read / batch | mitigate | `io.LimitReader` caps body at ~2 MB; `context.WithTimeout` caps each fetch at ~10s; bounded-concurrency semaphore caps in-flight fetches; request body also LimitReader-bounded |
| T-31-05 | Spoofing/Tampering | `HandleLoad` caller auth | mitigate | constant-time Bearer check (`authOK`) rejects unauthenticated callers on villa.network; real crypto/rand secret supplied in Plan 03 |
| T-31-06 | Tampering | prompt injection in fetched `page_content` | accept (deferred) | OUT OF SCOPE for Phase 31 — the sanitize/normalize/fence/classify seam is stubbed-but-present here; the policy lands in Phase 32 (GUARD-02/03/04). NEVER claim injection-safety; no "injection-safe" copy in this package |
| T-31-07 | Tampering | web content poisoning durable memory | transfer | dedicated ephemeral collection isolation is enforced by OWUI config in Plan 03 (GROUND-02), not by this core |
</threat_model>
