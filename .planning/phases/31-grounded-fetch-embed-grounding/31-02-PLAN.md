<objective>
Land the two contract-bearing core changes Phase 31 needs, both gated on `WebSearchEnabled`
and both byte-identical when off:

1. `recommend` reserves a web-search context budget BEFORE the chat-model fit (GROUND-03)
   — mirroring the shipped `MemoryInputs`/`memoryReservation`/`EmbeddingReservationBytes`
   seam exactly — so a search-enabled envelope cannot silently CPU-fall-back. This carries
   the single sanctioned recommend contract bump for Phase 31 (schema 3→4, one intentional
   golden re-freeze).
2. `config.VillaConfig` gains the websafe service identity fields + the external-loader
   bearer secret + the host binary path (for the bind-mount), with the same omit-when-off
   marshal + addr/port self-heal discipline as the SearXNG fields.

This plan is independent of Plan 01 (disjoint files: `internal/recommend`, `internal/config`),
so both run in Wave 1. Plan 03 (render/cmd) consumes the new config fields + the reservation.

Purpose: GROUND-03 (fit safety under search load) is a pure-core invariant that must land
where the fit math changes; the config fields are the single source of truth Plan 03 threads
into the render. Output: extended recommend + config cores with re-frozen goldens.
</objective>
